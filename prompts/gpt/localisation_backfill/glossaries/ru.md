# Русский — glossaire éditorial Collection

Version : `1.0-candidate` · locale cible : `ru`.

> Validé sur le lot test de quatre fiches et quarante localisations, note globale 8,5/10.

## Note de marché

Use natural collector/model-painting Russian. 'Под покраску' is useful in titles/tags; in prose, 'для покраски' is more neutral.

## Formulations préférées

- `sculptor_label` : **Скульптор:**

- `collectible_figure` : **коллекционная фигурка** · **коллекционная фигурка из смолы**
- `collectible_statue` : **коллекционная статуя** · **статуэтка из смолы**
- `paintable` : **неокрашенная фигурка** · **фигурка под покраску** · **фигурка для покраски**
- `ready_to_paint` : **готова к грунтовке и покраске** · **подготовлена к покраске**
- `garage_kit` : **гараж-кит из смолы** · **неокрашенный гараж-кит**
- `resin_kit` : **набор из смолы для сборки** · **модель из смолы для сборки и покраски**
- `3d_printed` : **фигурка из смолы, напечатанная на 3D-принтере** · **3D-печатная статуя из смолы**
