# Glossaires éditoriaux du backfill

Ces fichiers sont des points d'injection. Leur contenu définitif sera rédigé par ChatGPT puis validé sur quatre fiches représentatives avant tout backfill massif.

Contrat :

- `STATUS: DRAFT` indique une structure encore vide ou incomplète ;
- `STATUS: CANDIDATE` indique un contenu prêt pour le banc d’essai de quatre fiches, mais pas encore validé ;
- `STATUS: VALIDATED` l'autorise après validation humaine ;
- `STATUS: REFERENCE` est réservé au français source, qui n’est jamais publié par le backfill ;
- conserver les rubriques, compléter les termes réellement utilisés sur le marché cible ;
- ne pas recopier le prompt complet dans chaque glossaire.
