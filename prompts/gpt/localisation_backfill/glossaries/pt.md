# Português europeu — glossaire éditorial Collection

Version : `1.0-candidate` · locale cible : `pt`.

> Validé sur le lot test de quatre fiches et quarante localisations, note globale 8,5/10.

## Note de marché

Use European Portuguese. Keep 'garage kit' as a hobby loanword; avoid the literal 'kit de garagem'.

- `sculptor_label` : **Escultor:**

- `3d_renders_presented` : **renderizações 3D apresentadas**
- `La Guêpe Silencieuse` : **A Vespa Silenciosa**

## Formulations à éviter

- rendimentos 3D
- renderizações 3D apresentados

- kit de garagem
- presente para pintor
- figura de impressora 3D
- estátua para colorir
