# 日本語 — glossaire éditorial Collection

Version : `1.0-candidate` · locale cible : `ja`.

> Validé sur le lot test de quatre fiches et quarante localisations, note globale 8,5/10.

## Note de marché

Employer les termes établis du modélisme japonais. Garder les noms officiels japonais lorsqu'ils sont connus de façon certaine ; sinon conserver le nom international plutôt que d'inventer une translittération.

## Formulations préférées

- `sculptor_label` : **造形師:**
- `scale_notation` : conserver exactement les formes **1/6**, **1/8**, **1/10**, etc., avec leur barre oblique

- `collectible_figure` : **コレクションフィギュア** · **レジンフィギュア**
- `collectible_statue` : **コレクタブルスタチュー** · **レジンスタチュー**
- `paintable` : **未塗装フィギュア** · **塗装用フィギュア**
- `ready_to_paint` : **下処理済み・塗装可能** · **下地塗装と塗装が可能**
- `garage_kit` : **ガレージキット** · **未塗装レジンガレージキット**
- `resin_kit` : **レジンキット** · **レジン製組み立てキット**
- `3d_printed` : **3Dプリント製レジンフィギュア** · **3Dプリント製レジンスタチュー**
- `painter_gift` : **フィギュア塗装愛好家へのギフト** · **模型塗装愛好家へのギフト**
- `geek_gift` : **アニメファンへのギフト** · **ゲームファンへのギフト** · **ファン向けギフト**
- `collector_gift` : **フィギュアコレクターへのギフト** · **コレクター向けギフト**

## Formulations à éviter

- ガレージ用キット
- 3Dプリンターのフィギュア
- 画家へのプレゼント
- 塗装済みと誤認させる表現

## Vocabulaire peinture, préparation et assemblage

- `primer` : **プライマー / サーフェイサー**
- `priming` : **下地塗装**
- `basecoat` : **ベースカラー / 基本塗装**
- `wash` : **ウォッシング**
- `glaze` : **グレーズ**
- `gradient` : **グラデーション**
- `highlight` : **ハイライト**
- `edge_highlight` : **エッジハイライト**
- `drybrush` : **ドライブラシ**
- `airbrush` : **エアブラシ**
- `varnish` : **トップコート / クリアコート**
- `dry_fit` : **仮組み**
- `support_marks` : **サポート痕**
- `light_sanding` : **表面の軽い研磨**
- `assembly_required` : **組み立てが必要**
