# Español — glossaire éditorial Collection

Version : `1.0-candidate` · locale cible : `es`.

> Validé sur le lot test de quatre fiches et quarante localisations, note globale 8,5/10.

## Note de marché

Use neutral international Spanish. Keep 'garage kit' as a hobby term; never translate it literally as a kit for a garage.

## Formulations préférées

- `sculptor_label` : **Escultor:**

- `collectible_figure` : **figura de colección** · **figura de resina de colección**
- `collectible_statue` : **estatua de colección** · **estatua de resina**
- `paintable` : **figura sin pintar** · **figura para pintar**
- `ready_to_paint` : **lista para imprimar y pintar** · **preparada para pintar**
- `garage_kit` : **garage kit de resina** · **garage kit sin pintar**
- `resin_kit` : **kit de resina** · **kit de modelo en resina**
- `3d_printed` : **figura de resina impresa en 3D** · **estatua impresa en 3D**
- `painter_gift` : **regalo para pintores de figuras** · **regalo para pintores de miniaturas**
- `geek_gift` : **regalo para fans del anime** · **regalo gamer** · **regalo para fans**
- `collector_gift` : **regalo para coleccionistas** · **regalo para coleccionistas de figuras**

## Formulations à éviter

- kit de garaje
- regalo para pintor
- figura de impresora 3D
- estatua para colorear
