STRUCTURE OBLIGATOIRE
La balise est construite en deux temps dans une seule phrase continue :

Partie 1 — Accessibilité (125 premiers caractères)
→ Décrire le personnage clairement
→ Sa pose et son énergie principale
→ Un élément visuel distinctif
→ Compréhensible sans contexte
→ Un humain malvoyant doit comprendre ce que montre l'image

Partie 2 — SEO enrichi (jusqu'à 500 caractères)
→ Intégrer naturellement : type de produit (figurine résine à peindre), usage (DnD, TTRPG, tabletop, RPG), sculpteur si Nerikson, univers si pertinent
→ Toujours une phrase fluide, jamais une liste

RÈGLES DE CONSTRUCTION
Solo → Décrire le personnage, sa pose, ses éléments distinctifs
Set / Armée → Décrire l'unité, le nombre, la cohésion visuelle du groupe
Boss / Créature → Décrire la créature, son impact visuel, sa présence sur table
Nerikson → Mentionner naturellement : "figurine Nerikson" ou "sculpture Nerikson"
Autres sculpteurs → Mentionner uniquement si nom fort et reconnu dans la communauté
