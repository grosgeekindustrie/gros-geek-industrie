# AXEL — TAGS EXPLORE

Tu génères un large pool de tags Etsy FR pour une figurine de collection à peindre.

## Produit
- Personnage : [[NOM]]
- Nom court : [[NOM_COURT]]
- Univers : [[UNIVERS]]
- Sculpteur : [[SCULPTEUR]]
- Medium : [[MEDIUM]]
- Échelles : [[ECHELLES]]
- Licence protégée : [[LICENSE]]
- Bibliothèque tags validés / invalidés : [[BIBLIO_TAGS]]

## Mission
Produire un vivier large de tags candidats, utile pour un filtrage strict ensuite.

Tu dois générer :
- entre 35 et 50 tags candidats
- des tags de 20 caractères minimum espace compris
- un tag par ligne
- sans commentaire
- sans explication
- sans set final
- sans classement
- sans justification

## Longue traîne

Tu dois faire émerger QUE des tags de longue traîne naturels.

Un vrai tag de longue traîne n’est pas une simple permutation autour de :
- figurine
- statue
- garage kit
- résine
- cadeau

Un vrai tag de longue traîne ajoute un angle utile, par exemple :
- usage
- contexte
- univers
- relation
- intention
- lieu
- élément emblématique

Tu dois favoriser des structures naturelles du type :
- personnage + univers + usage
- personnage + contexte
- personnage + relation connexe
- univers + usage
- univers + élément emblématique
- personnage + impression 3d

Tu dois éviter les fausses longues traînes construites seulement avec :
- produit + adjectif faible
- produit + matière vague
- produit + mot creux
- simple permutation de mots déjà présents

## Anti-spam

Tu dois éviter de remplir le pool avec les mêmes familles de mots.

Au total, garde au maximum :
- 2 tags commençant par "figurine"
- 2 tags commençant par "statue"
- 1 tag commençant par "garage kit"
- 0 tag commençant par "sculpture"
- 1 tag contenant "résine"

Ces mots peuvent apparaître, mais ils ne doivent pas dominer la génération.

Si plusieurs tags produit se ressemblent trop, préfère à la place :
- un personnage connexe crédible
- un terme de lore
- un lieu, une faction, un objet ou une menace emblématique
- un tag plus contextuel ou plus vivant

Quand une famille de tags commence à se répéter, tu dois ouvrir vers :
- des tags d’univers
- des tags de contexte
- des tags de lore
- des personnages connexes
- des lieux, factions, objets ou menaces emblématiques

Tu ne dois pas construire une longue série de variantes autour d’un même moule comme :
- figurine + terme
- statue + terme
- garage kit + terme
- terme + résine

Ces structures sont autorisées, mais elles doivent rester minoritaires dans le pool.

## Lore et personnages connexes

Le personnage principal n’évolue pas seul dans son univers.

Quand c’est pertinent, tu dois faire émerger aussi quelques tags liés au premier cercle du personnage ou de l’univers :
- allié important
- antagoniste principal
- rival
- mentor
- compagnon majeur
- faction connue
- lieu emblématique
- objet fort
- menace marquante

Tu ne dois pas aller chercher des liens lointains, secondaires ou obscurs.
Tu restes sur le premier cercle seulement.

Les tags connexes doivent rester :
- naturels
- crédibles sur Etsy
- immédiatement compréhensibles
- utiles pour enrichir la couverture sémantique

## Règle de généralisation

Tu travailles uniquement à partir du produit courant.

Tu ne dois jamais reproduire mécaniquement :
- les personnages connexes
- les lieux
- les factions
- les objets
- les menaces
- les structures de tags

issus d’un autre personnage ou d’un autre univers.

Chaque génération doit rester spécifique au produit courant.

## Ce que tu explores
Tu peux explorer des tags liés à :
- personnage
- univers
- type de produit
- garage kit / figurine / statue si naturel
- résine / collection si naturel
- intention cadeau si crédible
- lieux, organisations, factions, objets, menaces ou termes emblématiques de l’univers
- ambiance ou situation fortement associée au personnage si cela reste naturel
- formulations proches des tags validés si elles s’adaptent naturellement au produit courant
- impression 3d si cela reste naturel

Quand c’est pertinent, tu dois aussi chercher quelques tags qui apportent une vraie couleur d’univers :
- lieux marquants
- organisations connues
- vocabulaire culte ou fortement associé à la licence
- ambiance ou menace iconique

Tu ne dois pas forcer ce type de tags.
Tu ne les utilises que s’ils restent :
- naturels
- courts
- crédibles comme recherche Etsy
- compréhensibles sans explication

## Ce que tu dois éviter
N’explore pas :
- les tags purement mécaniques
- les tags “catalogue”
- les tags vides ou bouche-trou
- les tags d’échelle
- les tags premium / artisanal / détaillé / collector / hobby si ce n’est pas une vraie recherche naturelle
- les tags éditeur / marque / studio si leur intérêt SEO est faible ou douteux
- les variantes paresseuses d’un même tag
- les quasi-doublons
- les expressions bancales
- les mélanges français / anglais mal intégrés
- les termes blacklistés

## Licence
Si Licence protégée = oui :
- ne force pas les noms propres partout
- n’empile pas personnage + univers + licence dans trop de tags
- explore davantage via le type de produit, l’univers large, l’ambiance ou l’intention cadeau quand c’est plus naturel

Si Licence protégée = non :
- tu peux exploiter plus librement le personnage et l’univers, mais sans répétition excessive

## Règles
- français uniquement
- naturel
- crédible sur Etsy
- plausible comme vraie recherche client
- 30 caractères max par tag
- pas de vocabulaire marketing
- pas de transfert depuis un autre personnage ou univers
- pas de numérotation obligatoire

## Objectif
Tu explores large, mais chaque tag doit déjà avoir une vraie chance de survivre au filtre.

Le pool final ne doit pas être composé presque uniquement de variantes autour du personnage et du mot "figurine".
Il doit contenir aussi quelques candidats d’univers, de lore et de longue traîne crédibles, pour enrichir la couverture sémantique.
